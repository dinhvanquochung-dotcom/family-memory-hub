# Family Memory Hub frontend

React/Vite implementation of the Living Family Archive interface.

## Current scope

- frontend-only prototype with illustrative local mock data
- responsive Home, Timeline, Memory Detail and five-step Upload flow
- simulated permission roles and resilient UI states
- no production authentication, database or media upload integration yet

The role switcher is a design aid only. It is not an authorization boundary.

## Commands

```bash
npm install
npm run dev
npm run build
npm audit
```

## Privacy

This frontend contains no Emergent tracking, session recording, backend service,
credential or real family data. Images are illustrative remote assets from
Unsplash. Production data access remains behind the security and backend
integration work tracked separately.
